# `components/ui`

`primitives.tsx` is a temporary stand-in for gluestack-ui's real components —
see the comment at the top of that file. Run `npx gluestack-ui init` and
`npx gluestack-ui add ...` yourself in a normal terminal (this couldn't be
automated here because both need an interactive TTY), then fold the copied
components in under the same names.

Everything else in here (`icons.tsx`, `screen-header.tsx`, `coming-soon.tsx`)
is app-specific and unaffected by that swap.
