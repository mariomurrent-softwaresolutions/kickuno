# kickuno — Hallenkick

Companion app for a recurring indoor football group: fixtures, RSVPs, team
building, results, and season/all-time statistics.

- `app/` — Expo (Expo Router, TypeScript, NativeWind) mobile app
- `cms/` — PayloadCMS backend (Next.js, MongoDB)
- `documentation/` — design prototype, implementation plan, and setup notes

Start here:

- [`documentation/implementation-plan.md`](documentation/implementation-plan.md) — full architecture, data model, and roadmap
- [`documentation/getting-started.md`](documentation/getting-started.md) — how to run `app/` and `cms/` locally, current status, known caveats
